# Split Range Valve Simulator 📱

เว็บแอป (PWA) จำลองและคำนวณการทำงานของ Split Range Valve — ติดตั้งบนมือถือได้ ใช้งานออฟไลน์ได้ ออกแบบมาสำหรับหน้าจอมือถือโดยเฉพาะ

## ฟีเจอร์

- 🎛️ จำลอง 3 โหมด: ตรงข้ามกัน (M), ตามลำดับ (N), แบบผสม (M+N)
- 📈 กราฟเส้น Valve Opening เทียบ MV พร้อมจุดวิ่งตามค่าปัจจุบัน
- 🎚️ สไลเดอร์ + ปุ่มจูนละเอียด ±0.1 / ±1 และพิมพ์ค่าตรงได้
- 🧪 เครื่องมือคำนวณย้อนกลับ (อยากให้วาล์วเปิดกี่ % → ต้องป้อน MV เท่าไหร่) คำนวณสดทันทีที่พิมพ์ พร้อมปุ่มส่งค่ากลับไปหน้าจำลอง
- 🌙 สลับธีมสว่าง/มืด (จำค่าที่เลือกไว้)
- 📳 Haptic feedback ตอนวาล์วแตะ 0% / 100%
- 📲 ติดตั้งเป็นแอป (PWA) ใช้งานออฟไลน์ได้เต็มรูปแบบ — ฟอนต์และไฟล์ทุกอย่างฝังอยู่ในตัว ไม่พึ่ง CDN

## วิธีเปิดใช้ GitHub Pages (ทำครั้งเดียว)

1. เข้า repo บน GitHub → **Settings** → **Pages**
2. ที่หัวข้อ **Build and deployment** เลือก Source = **Deploy from a branch**
3. เลือก Branch = branch หลักของ repo, Folder = **/ (root)** แล้วกด **Save**
4. รอประมาณ 1–2 นาที จะได้ URL รูปแบบ `https://<username>.github.io/Spit-range-Valve-/`

## วิธีติดตั้งบนมือถือ (Android / Samsung)

1. เปิด URL ของ GitHub Pages ใน **Chrome** หรือ **Samsung Internet**
2. Chrome: เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก** → **ติดตั้ง**
   Samsung Internet: เมนู ≡ → **เพิ่มหน้าปัจจุบัน** → **หน้าจอหลัก**
3. จะได้ไอคอนแอปบนหน้าจอ เปิดแบบเต็มจอไม่มีแถบเบราว์เซอร์ และใช้งานได้แม้ไม่มีเน็ต

## รันทดสอบบนเครื่อง

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

> หมายเหตุ: Service Worker ต้องการ HTTPS หรือ localhost เท่านั้น (เปิดไฟล์ตรงๆ แบบ `file://` จะใช้โหมดออฟไลน์ไม่ได้ แต่ตัวแอปยังทำงานปกติ)
